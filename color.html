Color Documentation

Variable Value Color Preview Description / Usage
--primary-color #0056A3
Main brand color. Used for primary buttons, headings, and brand elements.
--primary-light #007FFF
Lighter variant of primary color. Used for hover states and emphasized elements.
--primary-dark #003366
Darker variant of primary color. Used for active states and depth effects.
--accent-color #00A8FF
Accent color for highlights, links, and interactive elements. Draws attention.
--success-color #4CAF50
Success states, confirmation messages, and positive feedback.
--warning-color #FFC107
Warning messages, cautionary alerts, and attention indicators.
--danger-color #F44336
Error states, destructive actions, and critical alerts.
--gray-light #F2F4F8
Light backgrounds, borders, and secondary elements.
--gray-medium #B0B8C3
Secondary text, disabled states, and placeholder content.
--gray-dark #555
Body text and secondary elements requiring emphasis.
--white #FFFFFF
Pure white for backgrounds and text on dark backgrounds.
--black #333333
Near-black for high-contrast text and strong emphasis.
--box-shadow 0 2px 5px rgba(0, 0, 0, 0.1)
Default shadow for cards, modals, and elevated elements.
--border-radius 10px
Standard border radius for buttons, cards, and containers.
